⚠️ キーを発行したら必ず制限をかけてください

静的サイトのため API キーはブラウザに露出します。以下は必須の設定です。

  1. Google Cloud で Maps JavaScript API / Map Tiles API / Routes API / Elevation API を有効化
  2. キーに HTTP リファラ制限（例: kuzu-noha.github.io/github.io/*）を設定
  3. キーに API 種別制限を設定（上記4つのみ許可）
  4. 日次クォータ上限を設定（想定利用量の2〜3倍で頭打ちに）
  5. 予算アラートを設定

プロフィールと走行設定

もっと速く走りたいときは2つの方法があります。 ① 車種を速いものに変える — 空気抵抗が小さくなり、 同じ出力でも速く走れます（実走と同じ物理です）。 ② 速度の倍率を上げる — 表示速度も景色の進みも そのまま倍になります。短時間でも「遠くまで行った感」が出るので、 続けるモチベーションに効きます。倍率を使っているときは実測値も併記されます。

速度が異常な値になったり大きく暴れる場合は「速度の求め方」を パワーから算出にしてください。一体型エアロバイクが返す ホイール回転数は内部カウントで実距離と対応しないことが多く、 そのまま速度に換算すると値が安定しません。パワーからの算出なら 物理計算に基づくので滑らかで、坂道では自然に遅くなります。
