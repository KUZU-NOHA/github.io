# KDP英語絵本 市場リサーチと企画候補（2026-10-26）

## 1. リサーチの限界（先に明記）
- この環境ではAmazonのベストセラーページや順位データに直接アクセスできず、`WebFetch` は外部ドメインに届きませんでした。
- したがって以下は **検索結果の要約（KDP系ブログ・書店ページ等）に基づく傾向** であり、実売数・順位の裏付けではありません。
- 出版前に、Amazon.com の「Children's Picture Books」ベストセラー、各候補のキーワード検索（サジェスト・競合のレビュー数/BSR）を人の目で確認することを推奨します。

## 2. 売れている絵本の特徴（検索で確認できた範囲）
| 観点 | 傾向 | 根拠の強さ |
|---|---|---|
| ジャンル | 社会性・感情学習(SEL)、就寝/ルーティン、多様性、人生の変化(引越し・入園・通院)、季節/祝日が需要安定 | KDP系ブログ複数(二次情報) |
| テーマ設定 | 「be kind」など広いテーマより、**1冊1つの具体的な学び**（例: 怒りの扱い方、初めての歯医者）が検索されやすい | KDP系ブログ(二次情報) |
| 形式 | 24〜48ページ、とくに32ページが標準。判型は8.5×8.5in(正方形)が定番 | 複数ガイドで一致 |
| 文体 | 韻を踏んだ短い文、繰り返し、読み聞かせ向けのリズム。動物の主人公が多い | 伝統出版の大ヒット例(If Animals Kissed Good Night系・累計300万部と版元記載)から需要を推定 |
| 競合 | 「簡単そうなニッチ」ほど飽和。品質差が勝負 | KDP系ブログ(2026年9月) |
| 購買者 | 子ども本人でなく親・祖父母・教師。ギフト需要と「悩みの解決」目的が強い | 一般的傾向(要検証) |

## 3. KDP制作・規約上の注意
- **ページ数**: ペーパーバックは最低24ページ。絵本は32ページで設計。
- **判型**: 8.5×8.5in。裁ち落としは外側・天地に0.125in（内ページ 8.625×8.75in）という情報が多いが、ガイドにより不一致があるため **KDP公式ヘルプで要最終確認**。文字は端から十分内側（公式は0.375in以上の目安）。
- **画像**: 300dpi、RGB。
- **AI生成物の申告**: KDPは、AI生成の本文・画像（表紙・挿絵含む）は出版時に申告が必要。「AI支援」は申告不要だが、AIで内容そのものを作ったものは編集しても「AI生成」扱い。**この絵本は挿絵がAI生成になるため申告前提**。
- 品質リスク: 手の崩れ・画像内の文字化け・キャラ不統一があると低評価や審査上の問題になりやすい（二次情報）。キャラクターの一貫性が最大の制作課題。

## 4. 企画候補5案（すべてオリジナル）
共通: 3〜6歳向け、32ページ、8.5×8.5in、各約300〜500語、韻または反復を使用。

1. **Moon Isn't Sleepy Yet**（就寝・韻文）
   小さなうさぎが「まだ眠くない」と月に話しかけ、夜の動物たちがひとつずつ眠っていく。就寝ルーティンの定番需要。差別化: 終盤の数見開きで画面が徐々に暗くなる色設計。
2. **Pebble and the Big Red Mad**（SEL・怒りの扱い方）
   くまのブルーノの「怒り」が風船のようにふくらむ。深呼吸・足踏み・話すという3つの対処を繰り返しで覚える。親が買う動機が最も明確。
3. **Pip Moves to a New Home**（引越し・環境変化）
   ハリネズミのピップが引越しで不安になり、新しい家で小さな発見を重ねる。巻末に保護者向け声かけメモ。
4. **Fern Visits the Dentist**（初めての歯医者・具体的な1テーマ）
   きつねのフェーンが初めての歯医者を経験。ニッチが狭く競合が少ない可能性。巻末に歯みがきチェック表。
5. **Willa Waits for Snow**（季節・忍耐）
   雪を見たことのない南の子ぎつねが、初雪を待ちきれず冬を迎える準備をする。冬〜年末ギフト需要。ただし今から出版すると今季は間に合わない可能性があるため優先度は低。

### 推奨制作順
**2 → 1 → 4 → 3 → 5**。理由: 悩み解決型(2)が購買動機最強、就寝(1)は定番で量が出る、4は狭いニッチで差別化、3は汎用、5は季節性で最後。

## 5. 画像生成について（要相談）
- ChatGPT/Codex の画像生成は、この環境から呼び出す手段がありません（APIキー・CLIなし）。
- 代替として接続済みの **Canva の `generate-image`** が使える可能性があります（未検証）。
- 品質面では **キャラの一貫性** が最大の課題で、全ページ同じ「キャラクターシート」を参照させる運用が必要です。
