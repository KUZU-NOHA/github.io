## 1. 基本方針

本サービスは、**体重・体脂肪率・心拍数・走行記録などの個人データを、
どの利用方法であっても当方のサーバーには送信しません。** これらはすべて
利用者のブラウザ内（`localStorage`）にのみ保存され、外部に送信されるのは
以下の「2. 利用方法ごとのデータの流れ」に明記した範囲に限られます。

## 2. 利用方法ごとのデータの流れ

### 2.1 無料（BYOK: 自分の API キーを使う場合）

- 利用者が入力した Google Maps Platform の API キーは、利用者のブラウザの
  `localStorage` にのみ保存され、当方のサーバーには一切送信されません。
- ルート検索・標高取得・3D地図表示・2D地図表示のために、**利用者のブラウザから
  直接** Google Maps Platform の各種 API が呼び出されます。この通信に関する
  Google 側の取り扱いは [Google のプライバシーポリシー](https://policies.google.com/privacy)
  に従います。

### 2.2 有料（サブスクリプション）

サブスクリプションを有効化した場合、以下のデータが追加で外部に送信されます。

| データ | 送信先 | 目的 |
|---|---|---|
| メールアドレス・ライセンスキー | 当方のバックエンド（Vercel 上で運用） | サブスクリプションが有効かどうかの確認 |
| メールアドレス・ライセンスキー | 決済代行事業者（Stripe） | 同上（バックエンドが照会のため中継） |
| 検索したいルートの緯度経度・GPXから間引いた地点の緯度経度 | 当方のバックエンド経由で Google Maps Platform | ルート検索・標高取得・地図画像取得の代理実行 |
| クレジットカード情報等の決済情報 | 決済代行事業者（Stripe）へ直接 | 決済処理。**当方のアプリ・バックエンドは決済情報を一切保持しません** |

- 体重・体脂肪率・心拍数・走行記録は、サブスクリプション利用時も
  上記の対象に含まれず、引き続き外部へは送信されません。
- バックエンド（Vercel）を経由した通信は、ホスティング事業者側の
  インフラログとして一時的に記録される場合があります。当方はこれらのログを
  本サービスの不正利用調査以外の目的には利用しません。
- 決済ページは決済代行事業者（Stripe）が運営する画面に遷移して
  行われ、そちらの [プライバシーポリシー](https://stripe.com/privacy)
  が適用されます。

## 3. Cookie 等について

本サービス自体は、ログイン状態の管理等を目的とした Cookie を使用しません。
API キー・ライセンスキー・体重や走行記録などの設定・記録は、すべて
ブラウザの `localStorage` に保存されます。ただし、Google Maps Platform の
地図表示や、決済代行事業者の決済ページでは、それぞれのサービス側の
Cookie が使用される場合があります。

## 4. データのエクスポート・削除

体重・走行記録等のデータは、アプリ内の機能からいつでもエクスポート
（CSV等）・全削除ができます（要件定義書 P-03）。サブスクリプションの
解約・ライセンスキーの削除は、設定画面から行えます。

## 6. 改定

本ポリシーの内容は、法令の変更や本サービスの機能変更に応じて
予告なく改定される場合があります。
