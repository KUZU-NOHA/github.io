この利用規約（以下「本規約」）は、【事業者名】（以下「当方」）が提供する
バーチャルサイクリングアプリ（以下「本サービス」）の利用条件を定めるものです。
利用者は、本サービスを利用することで本規約に同意したものとみなします。

## 第1条（本サービスの内容）

本サービスは、Bluetooth 対応のスマートトレーナー等と連動し、実在する街並みの3D映像・
2D地図を表示しながら走行できる Web アプリです。以下の2通りの利用方法を提供します。

1. **無料（BYOK）**: 利用者自身が取得した Google Maps Platform の API キーを、
   本サービスの設定画面に入力して利用する方法。この方法における Google Maps
   Platform の利用は、利用者と Google との間の契約（Google Maps Platform
   利用規約）に基づく。
2. **有料（サブスクリプション）**: 当方が用意する API キーを、有効なサブスクリプション
   契約のもとで代理利用できるようにする方法。決済は決済代行事業者（Lemon Squeezy）を
   通じて行う。

## 第2条（アカウントとライセンスキー）

1. 有料プランの利用にあたり、当方はログイン・パスワードによるアカウント登録を求めない。
   決済完了時に発行されるライセンスキーを本サービスの設定画面に入力することで
   利用を有効化する。
2. ライセンスキーは、購入者本人のみが利用するものとし、第三者への譲渡・共有・
   転売を禁止する。不正な共有が検知された場合、当方は当該キーを無効化できるものとする。

## 第3条（禁止事項）

利用者は、本サービスの利用にあたり、以下の行為をしてはならない。

- 法令または公序良俗に違反する行為
- ライセンスキーの不正な共有・転売、または本サービスのバックエンドへの過度な
  負荷をかける行為
- 本サービスが中継する Google Maps Platform のコンテンツを、Google Maps Platform
  利用規約に反する方法（無断キャッシュ・バルクダウンロード等）で取得・保存する行為
- 本サービスのリバースエンジニアリング等により、他の利用者のライセンスキーや
  当方の API キーを不正に取得しようとする行為

## 第4条（料金・支払い）

1. 有料プランの料金は、本サービス上またはウェブサイト上に別途表示する額とする。
2. 決済は決済代行事業者（Lemon Squeezy）を通じて行われ、当方はクレジットカード
   番号等の決済情報を保持しない。
3. 解約方法・返金の扱いは [特定商取引法に基づく表記](./tokushoho.md) の定めによる。

## 第5条（無料プランの継続提供）

自分の API キーを設定画面に入力して利用する方法（BYOK）は、当方の判断で
本サービスの提供自体を終了する場合を除き、有料プランの提供状況にかかわらず
無料で提供を継続する。

## 第6条（免責事項）

1. 本サービスは Google Maps Platform・Bluetooth デバイスの仕様・提供状況に
   依存しており、これらの変更・停止により本サービスの一部または全部が
   利用できなくなる場合がある。当方はこれによる損害について責任を負わない。
2. 本サービスが表示する経路・距離・消費カロリー・心拍数等は、GPS・センサーの
   精度に起因する誤差を含みうる推定値であり、正確性を保証しない。
3. 本サービスは医療機器ではなく、運動処方や診断を目的としたものではない。
   持病がある場合や運動に不安がある場合は、事前に医師に相談すること。
4. 当方は、本サービスの利用によって生じた利用者の損害について、当方の
   故意または重過失による場合を除き、責任を負わない。

## 第7条（サービス内容の変更・終了）

当方は、利用者への事前の通知をもって、本サービスの内容を変更し、または
提供を終了できるものとする。有料プランを終了する場合、既払い分の日割り
返金等の扱いは別途案内する。

## 第8条（規約の変更）

当方は、必要と判断した場合、本規約を変更できるものとする。変更後の規約は、
本サービス上での掲示をもって効力を生じる。

本規約は日本法に準拠する。本サービスに関して紛争が生じた場合、
【管轄裁判所】を第一審の専属的合意管轄裁判所とする。
