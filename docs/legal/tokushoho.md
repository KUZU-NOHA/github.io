# 特定商取引法に基づく表記（テンプレート）

> ⚠️ **これは未完成のテンプレートです。** サブスクリプション課金を開始する（Phase B）前に、
> 下記の `【　】` 部分をすべて実際の情報に置き換え、可能であれば法律の専門家（弁護士・
> 行政書士等）にも内容を確認してもらってから、実際のアプリ上に公開してください。
> このテンプレートは特定商取引法が要求する一般的な項目の雛形を提供するものであり、
> 法的助言ではありません。
>
> 特に、個人事業主が住所・電話番号をそのまま公開する代わりに「請求があれば遅滞なく
> 開示する」旨の記載で代替できるかどうかは、事業形態や取り扱う決済代行事業者の規約に
> よって扱いが異なります。公開前に必ず最新の消費者庁のガイドラインと、決済代行として
> 使う Stripe 側の要件（マーチャント・オブ・レコードとしての表示義務の分担範囲）
> の両方を確認してください。

## 表記事項

| 項目 | 内容 |
|---|---|
| 販売事業者 | 【氏名または屋号】 |
| 運営責任者 | 【氏名】 |
| 所在地 | 【住所。個人事業主としての開示方法は上記の注意書きを参照】 |
| 電話番号 | 【電話番号。同上】 |
| メールアドレス | 【問い合わせ用メールアドレス】 |
| 販売URL | 【アプリの公開URL】 |
| 販売価格 | 【月額 ○○円（税込）。要件定義書 第12章のとおり本稿執筆時点では未確定】 |
| 商品代金以外の必要料金 | 決済手数料等はすべて上記価格に含む（決済代行 Stripe 経由での課金） |
| 支払方法 | クレジットカード等、Stripe が対応する決済手段に準ずる |
| 支払時期 | 購入時に初回課金。以降は毎月同日に自動課金（Stripe 側の仕様に準ずる） |
| サービス提供時期 | 決済完了後、即時（決済完了後のリダイレクトでアプリにライセンスキーが自動反映される） |
| 返品・キャンセルについて | 【返金ポリシーを記載。例: デジタルサービスの性質上、原則として返金不可。ただし◯日以内の申し出は全額返金、など。要確定】 |
| 解約方法 | アプリの設定画面のライセンスキー欄から「解除」を押すと当アプリでの機能利用は停止できる。**自動更新（課金）自体を止めるには、Stripe が提供するカスタマーポータル（購入完了メールに記載のリンク）から解約手続きを行う必要がある**旨を明記すること |
| 動作環境 | 要件定義書 第3章参照（Chrome / Edge / Opera / Samsung Internet を推奨。iPhone の Safari は Web Bluetooth 非対応のためトレーナー接続不可） |
