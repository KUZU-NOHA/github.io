WHERE TO RIDE

好きな街を、好きなだけ走る。

同梱のプリセットは実際に記録・計画されたGPXなので、APIキーが無くても正確な道と標高で走れます。

  • 東京・大阪・サンフランシスコ・パリなど、同梱プリセットから選ぶ
  • 手持ちの GPX ファイルをそのままインポート
  • 地図上で地点を指定して、その場でルート生成

WHAT YOU SEE

今の自分が、数字でそのまま見える。

スマートトレーナーから速度・ケイデンス・パワー・心拍を取得。標高から勾配を計算し、坂道はトレーナーの負荷に反映されます。

  • 坂道では実際にペダルが重くなる（勾配連動）
  • 消費カロリーはパワー計があれば実測ベースで算出
  • お気に入りルートは、自己ベストとの前回比が出る

※ 画面の数値は、機材なしで試せるシミュレーター機能によるものです

WHAT KEEPS YOU GOING

「続いている」が、目に見える。

週間の消費カロリー、直近30日、連続日数、心拍ゾーン滞在時間。積み上がっていく記録が、次に漕ぐ理由になります。

  • 体重を4回以上記録すると、目標達成予測日が出る
  • 心拍ゾーン（脂肪燃焼帯）の滞在時間を可視化
  • 記録は CSV / JSON でいつでも書き出し・全削除できる

スマートトレーナーが無くても、まず試せます。

擬似出力スライダーで動くシミュレーターモードを内蔵。機材の有無にかかわらず、その場で3分あれば体験できます。

BEFORE YOU START

よくある質問

iPhoneでも使えますか？
Web BluetoothはiPhoneのSafari・Chromeどちらも非対応です。App Storeの「WebBLE」という専用ブラウザ（有料）経由なら接続できますが、実機での動作は確認しきれていません。まずはPC・MacのChromeでの利用をおすすめします。
どんなスマートトレーナーに対応していますか？
FTMS・Cycling Power・CSCのいずれかのBluetoothサービスを持つ機種に対応しています。心拍サービスしか広告しない一体型エアロバイクも、接続後に中身を調べて拾えるようにしています。機材が無くてもシミュレーターモードで試せます。
「テスト期間中は無料」は、いつまでですか？
自分のGoogleアカウントでAPIキーを発行して使う方法（BYOK）は、今後も無期限で無料です。それ以外の便利機能も、今は検証期間として全て無料で開放しています。将来的に一部を有料化する可能性はありますが、その場合も今の無料の使い方自体は変わりません。
APIキーや走行データはどこかに送信されますか？
入力したAPIキーは、この端末のブラウザ内にのみ保存され、外部には送信されません。体重や走行記録も同様に、ブラウザの外に出ることはありません。
個人開発ですか？
はい、個人で開発しています。既存アプリの月額料金に疑問を感じたのがきっかけです。感想・不具合報告はSNSでのコメントや引用で教えてもらえると助かります。
