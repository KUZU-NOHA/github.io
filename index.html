🚴 バーチャルサイクリング

Google マップの 3D 地図の中を、自分が漕いだぶんだけ進む。 Bluetooth スマートトレーナーと連携し、坂道では実際にペダルが重くなります。 ダイエットの継続を支えるための室内サイクリングアプリです。

アプリを開く →

⚠️ 動作環境

Bluetooth 接続には PC / Mac の Chrome が必要です。 iOS の Safari と iOS 版 Chrome は Web Bluetooth に対応していないため、 iPhone では App Store の WebBLE ブラウザからお使いください。 機材が無くてもシミュレーターモードで全機能を試せます。

できること

  • フォトリアルな 3D 地図の中を走る（実質無料で使えるセッション課金）
  • スマートトレーナー(FTMS)から速度・ケイデンス・パワー・心拍を取得
  • ルートの標高から勾配を計算し、トレーナーの負荷へ反映
  • 消費カロリーの算出（パワー計があれば実測ベース、無ければ METs 推定）
  • 体重推移・週間カロリー・連続日数の記録
  • プリセットルート / GPX インポート / 地点指定でのルート生成

使いはじめる

  1. Google Cloud で API キーを発行し、Maps JavaScript API / Map Tiles API / Routes API / Elevation API を有効化
  2. キーに HTTP リファラ制限・API 種別制限・日次クォータ上限・予算アラートを設定
  3. アプリの設定画面でキーを入力（キーはこの端末のブラウザにのみ保存されます）

キーが無くても 2D 表示モードで動作するので、まず触ってみることができます。
